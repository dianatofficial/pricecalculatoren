# سامانه محاسبه‌گر قیمت خدمات دانشگاهی و پژوهشی

این وب‌اپلیکیشن کاربردی و جامع جهت محاسبه، برآورد و استعلام هزینه پروپوزال، پایان‌نامه (کارشناسی ارشد و دکتری)، مقالات علمی، استخراج مقاله از پایان‌نامه، اقدام‌پژوهی و خلاصه‌نویسی مقالات به همراه محاسبه دقیق تخفیف‌های حجمی و برآورد زمان تحویل طراحی و پیاده‌سازی شده است.

---

## 🚀 ویژگی‌های کلیدی سامانه

1. **پشتیبانی کامل دو زبانه (فارسی و انگلیسی):**
   - امکان تغییر آنی زبان رابط کاربری (Bilingual Toggle) با حفظ وضعیت و مقادیر ورود داده شده.
   - طراحی بهینه و واکنش‌گرا (Responsive) با پشتیبانی کامل از پوسته تاریک و روشن (Dark / Light Mode).

2. **ماژول‌های محاسبه‌گر تخصصی:**
   - **پایان‌نامه و رساله:** انتخاب مقطع (ارشد / دکتری)، گروه رشته، نوع کار تخصصی، سطح خدمات (استاندارد، حرفه‌ای، ویژه)، نوع دانشگاه و زمان تحویل.
   - **پروپوزال:** برآورد دقیق هزینه نگارش پروپوزال با قابلیت انتخاب محدوده و حجم کار (مرور ادبیات جامع، مطالعه مقدماتی و...).
   - **مقالات علمی (ISI / Scopus / همایشی / علمی پژوهشی):** محاسبه قیمت بر اساس سطح و ایندکس مقاله، زبان نگارش (فارسی یا نگارش مستقیم انگلیسی) و زمان تحویل.
   - **استخراج مقاله از پایان‌نامه:** برآورد هزینه استخراج، بازنویسی، فرمت‌بندی و آماده‌سازی مقاله بر اساس گروه رشته و ایندکس هدف.
   - **اقدام‌پژوهی:** محاسبه هزینه بر اساس مقطع/سطح مشخص، حوزه تخصصی و پیچیدگی اجرا.
   - **خلاصه‌نویسی و فیش‌برداری مقالات:** پشتیبانی از تخفیف‌های حجمی پلکانی بر اساس تعداد مقالات.

3. **نمایش ریز محاسبات و مقایسه قیمت:**
   - نمایش تفکیکی قیمت پایه، ضرایب تخصصی رشته، هزینه خدمات اضافه و تخفیف‌های اعمال شده.
   - قابلیت مقایسه قیمت محاسبه شده با میانگین قیمت بازار و برآورد میزان صرفه‌جویی.

## 🛠 فناوری‌های استفاده‌شده

- **فریم‌ورک:** Angular (مبتنی بر Zoneless Architecture و Signals)
- **طراحی و استایل:** Tailwind CSS
- **زبان برنامه‌نویسی:** TypeScript

---

## ⚙️ راهنمای اجرا و راه‌اندازی

برای اجرای پروژه روی محیط محلی، مراحل زیر را انجام دهید:

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. اجرای سرور توسعه
```bash
npm run dev
```
اپلیکیشن در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۳. ساخت نسخه نهایی (Production Build)
```bash
npm run build
```
